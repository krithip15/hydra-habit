# Database Schema

HydraHabit uses PostgreSQL with SQLAlchemy ORM.

## Tables

### users

Stores the user's profile and hydration preferences.

| Column                  | Type    | Description             |
| ----------------------- | ------- | ----------------------- |
| id                      | Integer | Primary key             |
| name                    | String  | User name               |
| age                     | Integer | Age                     |
| gender                  | String  | Gender                  |
| height_cm               | Float   | Height                  |
| weight_kg               | Float   | Weight                  |
| health_goal             | String  | Hydration-related goal  |
| daily_water_target_ml   | Integer | Daily target            |
| preferred_reminder_time | String  | Preferred reminder time |
| health_limitation       | String  | Optional limitation     |

### hydration_records

Stores daily water intake.

| Column          | Type    | Description          |
| --------------- | ------- | -------------------- |
| id              | Integer | Primary key          |
| user_id         | Integer | Foreign key to users |
| date            | Date    | Hydration date       |
| water_intake_ml | Integer | Water intake         |

A user can have multiple hydration records across different dates.

### recommendations

Stores recommendations generated by the agent.

| Column              | Type     | Description          |
| ------------------- | -------- | -------------------- |
| id                  | Integer  | Primary key          |
| user_id             | Integer  | Foreign key to users |
| date                | Date     | Recommendation date  |
| insight             | Text     | Agent insight        |
| recommendation_text | Text     | Recommendation       |
| action_type         | String   | Agent action         |
| confidence          | String   | Confidence level     |
| created_at          | DateTime | Creation time        |

### agent_execution_logs

Stores the agent's execution history.

| Column           | Type     | Description              |
| ---------------- | -------- | ------------------------ |
| id               | Integer  | Primary key              |
| user_id          | Integer  | Foreign key to users     |
| tool_name        | String   | Executed agent/tool step |
| tool_input       | JSON     | Input provided           |
| tool_output      | JSON     | Result                   |
| decision_summary | Text     | Decision explanation     |
| final_action     | String   | Final action             |
| created_at       | DateTime | Execution time           |

## Relationships

```text
users
  │
  ├──< hydration_records
  │
  ├──< recommendations
  │
  └──< agent_execution_logs
```
